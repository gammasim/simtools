Calculate night-sky background scaling in simtools and add `--disable_nsb_autoscaling` to disable the zenith-dependent correction. The applied NSB rate factor (`nsb_applied_scaling_factor`, per telescope) and the autoscaling state (`nsb_autoscaling`) are recorded in the sim_telarray metadata. Add `--zenith_angle` to `simtools-generate-array-config` to write configurations with the NSB scaling of that zenith angle.
