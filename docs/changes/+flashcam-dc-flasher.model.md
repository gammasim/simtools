Add the DC flat-fielding element type `MSF2` (`MSF2-FlashCam`), the model parameters `flasher_dc_pixel_rate` and `flasher_dc_relative_pixel_map`, and the calibration device key `flat_fielding_dc`.

Flat-fielding unit MSF1 (pulsed) is the element type of MSFx and bare MSF names; MSF1 names use the MSFx model parameter directories.
