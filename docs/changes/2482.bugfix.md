Fix sign error in `_rotate_azimuth_by_180deg` that caused zero camera hits for azimuths other than 0° and 180°. CORSIKA uses a left-handed coordinate system, so the geographic azimuth must be negated before applying the +180° travel-direction reversal. The corrected formula `(-az + 180 + D) % 360` is also self-inverse, making the `invert_operation` parameter redundant (kept for backward compatibility).
