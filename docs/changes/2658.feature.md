Add a `simtools-compare-atmospheres` application to compare atmospheric profile and
transmission model parameters for one or more site and parameter-version combinations.
It plots profiles and direct transmission with differences relative to the first
atmosphere and writes a JSON summary. Move `simtools.atmosphere` to
`simtools.atmosphere.atmosphere`, and support repeated multi-value options
(e.g., `atmosphere: [[North, 1.0.0, 1.0.0], [South, 1.0.0, 1.0.0]]`) in configuration files.
