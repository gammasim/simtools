Simulation chains are checked when they are read: chains that apply an efficiency factor twice (atmospheric extinction, mirror reflectivity, telescope transmission, quantum efficiency) or leave out a factor required by their source are rejected. obdeect stages take one array model per run, so several model versions in one run are rejected. The installed sim_telarray is checked for camera-only support (``Bypass_Optics=3``) before jobs are written. The dependency catalog schema 0.10.0 renames the ``sim-telarray`` entry to ``sim_telarray``.
