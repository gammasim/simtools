# simtools-plot-trigger-patches

```{eval-rst}
.. automodule:: simtools.applications.plot_trigger_patches
   :members:
   :exclude-members: main
```

Plot the camera trigger groups and bracketed pre-summed pixel patches for a
telescope model. Heavy outlines show pre-summed members and ``+`` marks the
required majority-trigger master pixel.

```{code-block} console
simtools-plot-trigger-patches --site North --telescope LSTN-01 --model_version 6.0.2
```
