This modules provides two main functionalities:

  • retrieve the versions of simtools dependencies (e.g., databases, sim_telarray, CORSIKA)

  • provide space for future implementations of version management

Resolve version-dependent values in a configuration dictionary.

Fields whose value is a dict with a single by_version key are replaced by the first matching constraint value. All other fields are left unchanged.

Parameters:
configdict

Configuration dictionary (typically loaded from a YAML file).

model_versionstr or list

Semantic version string or list of strings used to evaluate constraints (e.g. “6.0.2” or [“6.0.2”, “6.1.1”]).

preserve_inconsistent_keysset, optional

Keys whose by_version mappings are retained when they resolve differently.

Returns:
dict

New dictionary with all by_version fields resolved to their matching value, or None when no constraint matches.

simtools.version.resolve_version_to_latest_patch(partial_version, available_versions)[source]#

Resolve a partial version (major.minor) to the latest patch version.

Given a partial version string (e.g., “6.0”) and a list of available versions, finds the latest patch version that matches the major.minor pattern.

Parameters:
partial_versionstr

Partial version string in format “major.minor” (e.g., “6.0”, “5.2”)

available_versionslist of str

List of available semantic versions (e.g., [“5.0.0”, “5.0.1”, “6.0.0”, “6.0.2”])

Returns:
str

Latest patch version matching the partial version pattern

Raises:
ValueError

If partial_version is not in major.minor format

ValueError

If no matching versions are found

Examples

>>> versions = ["5.0.0", "5.0.1", "6.0.0", "6.0.2", "6.1.0"]
>>> resolve_version_to_latest_patch("6.0", versions)
'6.0.2'
>>> resolve_version_to_latest_patch("5.0", versions)
'5.0.1'
>>> resolve_version_to_latest_patch("5.0.1", versions)
'5.0.1'
