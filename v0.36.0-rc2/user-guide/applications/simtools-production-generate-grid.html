simtools-production-generate-grid#

Generate a simulation production grid for a wide range of simulation parameters.

Overview#

The application expands a grid of simulation configuration parameters to be used for a simulation production. Possible axes include particle type, simulation model version, interaction models, and pointing directions such as azimuth, zenith, hour angle, and declination.

The generated grid can be used as input for local production execution or workload-management submission tools. Different levels of night-sky background (NSB) can be configured through the production model version.

Input/Output#

The application reads and writes the following user-visible files:

Role

Argument

Format

Purpose

Schema

Input

corsika_limits

ECSV

Lookup table for CORSIKA simulation limits (optional).

corsika_limits_table.schema.yml.

Output

output_file

ECSV

Executable production job grid.

job_grid_density.schema.yml.

Defining the number of showers#

showers_per_run is required and defines the baseline number of CORSIKA showers in one job. For every combination of primary, model version, interaction model, pointing, and energy interval, the application first determines the showers in each generated job and then determines how many jobs to create. The resulting value is written to the showers_per_run column; the unscaled configured value is retained in configured_showers_per_run.

Choose one of the following allocation modes:

Mode

Configuration

Result

Fixed number of jobs

Set number_of_runs.

Creates that many jobs for every grid point and energy interval. The total is number_of_runs * showers_per_run after any per-run scaling. If omitted, one job is created.

Target number of showers

Set total_showers.

Creates enough equal-sized jobs to meet the target at every grid point and energy interval. This cannot be used with number_of_runs.

With total_showers, the target is rounded up to a whole number of jobs. For example, total_showers: 2500 and showers_per_run: 1000 create three jobs of 1000 showers, for an actual total of 3000. A warning reports each such adjustment; max_total_showers_rounding_warnings limits how many of these warnings are emitted (20 by default).

The following options alter the shower allocation. Per-run scaling is applied before the number of jobs is determined, so it affects the total when number_of_runs is used and the required number of jobs when total_showers is used.

Option

Choices or value

Effect

showers_per_run_power_law

INDEX REFERENCE_ENERGY

Scales the baseline per-run value by (E_mid / E_ref)^INDEX, where E_mid is the logarithmic midpoint of the selected energy interval. The result is rounded up to an integer. Omit it, or use index 0, to keep the per-run count independent of energy.

showers_per_run_scaling

fixed (default), cosine_zenith

cosine_zenith sets the per-run value to ceil(N * cos(zenith)); fixed leaves it unchanged.

total_showers_scaling

fixed (default), zenith_scaled

Applies only with total_showers. zenith_scaled changes the target to ceil(N * exp(F * (cos(zenith) - 1))), where F is zenith_angle_scaling_factor (3.9781 by default).

total_showers_scaling changes the requested total, whereas showers_per_run_scaling changes the size of each job. They can be combined: the first sets a zenith-dependent target and the second sets a zenith-dependent job size, after which the application rounds the number of jobs up as needed.

Command line arguments#

options#

–help

show this help message and exit

–axis

Grid axis as NAME MIN UNIT MAX UNIT POINTS [SCALING]. Repeat for each axis. Use azimuth/zenith or ha/dec, plus offset. SCALING is linear, log, or 1/cos.

–direction_grid_density

Direction-point density in deg^-2. Overrides POINTS for both direction axes.

–local_zenith_range

Accepted local zenith range for an HA/Dec density grid, e.g. 0 deg 70 deg.

–local_azimuth_range

Accepted local azimuth range for an HA/Dec density grid. Ranges may wrap through 0 deg.

–output_file

Output ECSV production job grid.

Default: job_grid.ecsv.

–corsika_limits

ECSV lookup table of direction-dependent CORSIKA simulation limits.

–total_showers

Target showers per grid point and energy interval; incompatible with –number_of_runs.

–total_showers_scaling

Total-shower zenith scaling. zenith_scaled applies N * exp(factor * (cos(zenith) - 1)).

Default: fixed. Choices: fixed, zenith_scaled.

–zenith_angle_scaling_factor

Factor in the zenith_scaled total-showers expression.

Default: 3.9781.

–max_total_showers_rounding_warnings

Maximum warnings emitted when total_showers is rounded up to complete runs.

Default: 20.

–showers_per_run_power_law

Scale showers per run by (E_mid / E_ref)^INDEX (mostly used for fixed energy grid). Provide INDEX VALUE UNIT; E_mid is the logarithmic energy-interval midpoint.

–showers_per_run_scaling

Showers-per-run zenith scaling. cosine_zenith applies ceil(N * cos(zenith)).

Default: fixed. Choices: fixed, cosine_zenith.

–energy_max_scaling

Set the zenith-dependent maximum energy to VALUE * cos(zenith)^INDEX. Provide INDEX VALUE UNIT; the configured energy-range maximum remains an upper bound.

simulation configuration#

–number_of_runs

Runs generated per grid point.

–primary

Primary particle(s) to simulate. Common names: gamma, electron, positron, muon+, muon-, proton, neutron, helium, carbon, nitrogen, silicon, iron. Use –show_options primary.

Required.

–primary_id_type

Primary particle ID type

Default: common_name. Choices: common_name, corsika7_id, pdg_id.

–azimuth_angle

Telescope pointing direction in azimuth. It can be in degrees between 0 and 360 or one of north, south, east or west. North is 0 degrees and the azimuth grows clockwise (East is 90 degrees).

–zenith_angle

Zenith angle in degrees (between 0 and 180).

Default: 20.0 deg.

–showers_per_run

Baseline number of CORSIKA showers per run.

Required.

–run_number_offset

Offset added to each run number.

–run_number

Run number to be simulated.

Default: 1.

–event_number_first_shower

Event number of first shower

Default: 1.

–correct_for_b_field_alignment

Align North with geographic North (and not magnetic North).

Default: True.

–curved_atmosphere_min_zenith_angle

Minimum zenith angle (deg) for using curved-atmosphere CORSIKA binaries.

Default: 65.0 deg.

simulation model#

–model_version

Simulation production model version(s). Use –show_options model_version.

Required.

–overwrite_model_parameters

File name to overwrite model parameters from DB with provided values

–site

Observatory site (e.g., North, South). Use –show_options site.

Required.

–array_layout_name

Array layout name(s) (e.g., CTAO-North-Alpha, LSTN-01). Telescope names are assumed as single-telescope layouts. Use –show_options array_layout_name.

Required.

simulation software#

–simulation_software

Simulation software workflow.

Default: corsika_sim_telarray. Choices: corsika, sim_telarray, corsika_sim_telarray.

shower parameters#

–eslope

Slope of the energy spectrum.

Default: -2.0.

–energy_range

Minimum and maximum primary energy, e.g. ‘10 GeV 5 TeV’.

Default: (<Quantity 3. GeV>, <Quantity 330. TeV>).

–view_cone

Minimum and maximum view-cone radius, e.g. ‘0 deg 10 deg’.

Default: [‘0 deg 0 deg’].

–core_scatter

Core positions per shower and maximum scatter radius, e.g. ‘10 500 m’.

Default: [‘10 10000 m’].

corsika configuration#

–corsika_he_interaction

High-energy interaction model for CORSIKA (default fallback: epos). Use –show_options corsika_he_interaction.

–corsika_le_interaction

Low-energy interaction model for CORSIKA (default fallback: urqmd). Use –show_options corsika_le_interaction.

–corsika_hadronic_transition_energy

Transition energy between the low- and high-energy CORSIKA hadronic interaction models. Unitless values are interpreted as GeV. If omitted, the CORSIKA build default is used.

database configuration#

–simulation_models_path

Path containing simulation model files; when set, model parameters are read from files instead of MongoDB.

–db_api_user

Database username.

–db_api_pw

Database password.

–db_api_port

Database server port.

–db_server

Database server address.

–db_api_authentication_database

Authentication database name.

–db_simulation_model

Simulation-model database name.

–db_simulation_model_version

Simulation-model database version.

application#

–show_options

Print available values for a supported option and exit.

Examples#

Generate an HA/Dec production grid#

Generate point-source simulation jobs at fixed hour-angle and declination offsets, applying tabulated CORSIKA limits.

Application: simtools-production-generate-grid

Integration test: production_generate_grid_ha_dec.yml

Command

simtools-production-generate-grid --config tests/integration_tests/config/production_generate_grid_ha_dec.yml

Configuration

array_layout_name: LSTN-01
axis:
- ha 0 deg 360 deg 36 linear
- dec -90 deg 90 deg 18 linear
- offset 0 deg 10 deg 2 linear
core_scatter: 10 500 m
corsika_he_interaction: epos
corsika_le_interaction: urqmd
energy_range: 30 GeV 300 GeV
corsika_limits: ${downloaded:corsika_limits.ecsv}
model_version: 7.0.0
showers_per_run: 5
showers_per_run_power_law: 0.0 1 TeV
number_of_runs: 2
output_file: job_grid_ha_dec.ecsv
output_path: simtools-output
primary: gamma
simulation_software: corsika_sim_telarray
site: North
view_cone: 0 deg 10 deg
